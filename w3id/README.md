# VAO persistent identifier routing

The 0.4.0 and 0.5.0 published routes retain their immutable release targets.
Canonical 0.6.0 and MMIC 1.0.0 identifiers are defined by the released normative
files; 0.6.0 resolver routing remains pending.

No W3ID pull request or resolver deployment is part of the 0.6.0 release. Use the
immutable GitHub release and versioned Zenodo record for access, and the local MMIC
dependency catalog for offline validation. Future routing work must verify exact
source tag/path, representation and byte identity while preserving older targets.

Stable vocabulary or profile delegation requires its own reviewed resolver registry,
redirect-chain checks and deployment decision. Publishing a VAO specification does
not make an undeployed route available or imply MODAVIS Network acceptance.
