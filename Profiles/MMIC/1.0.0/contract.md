# MMIC 1.0.0 application profile contract

This profile is governed by the [normative profile](../../../Docs/VAO_MMIC_PROFILE_1.0.0.md),
closed `mmic.schema.json`, local `dependencies.json` and exact `registry.json` in
this directory. The profile version is independent of its VAO `0.6.0`
envelope. The standalone mechanical-music module is VAO-owned; it is not an
accepted MODAVIS network module. Version 0.6.0 resolver routing is pending.

Documentation, decoding, comparison and generation are separate conformance
levels. Native actuation is primary, MIDI export optional. Complete model identity,
selector/timing/binding/byte consistency and fabrication lineage are required.
The schema and original reference tools implement the released contract; all
historical-model certification remains outside structural conformance.

Normative resources use CC BY 4.0. Original synthetic fixture data uses CC0-1.0;
distributed reference code and dependency-lock assets retain Apache-2.0. The
repository REUSE.toml defines the complete per-file mapping.
