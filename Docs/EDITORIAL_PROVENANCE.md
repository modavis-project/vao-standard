# Editorial provenance

## VAO 0.4.0

VAO 0.4.0 established the first public specification with immutable schema, context, profile, and tool identifiers. Earlier 0.3 material remains only as migration input and retained-semantic regression data; it is not a public VAO baseline.

The 0.4.0 review covered archive safety, deterministic serialization and runtime behaviour, scientific quantity and provenance semantics, multimodal clocks, spatial and acoustic validity boundaries, linked-data projection, schemas, fixtures, licensing, governance, citation, and registry metadata. Its signed tag is `v0.4.0` and its version DOI is `10.5281/zenodo.22122774`.

## VAO 0.5.0

VAO 0.5.0 retains the scientific, physical-system, playable, runtime, provenance, and rights contracts of 0.4.0. It adds carrier identity, the `carrier-member` distribution, descriptor and carrier fixity in the release inventory, release-to-carrier cross-validation, and a two-carrier repository profile for bootstrap and preservation delivery.

The final review verified the normative 0.5.0 artifact bundle, both reference-tool generations, cross-carrier fixtures, deterministic builds, licensing, citation metadata, publication pages, and W3ID targets. Candidate labels used during review were repository labels only and never valid serialized `formatVersion` values.

The signed tag `v0.5.0`, the GitHub release, the publication site, and Zenodo version DOI `10.5281/zenodo.22214248` identify the final release. The 0.4.0 artifacts remain immutable and available under their original version identifiers.
